# 产品方案（原始完整版）

> **一个完全离线的照片去重工具：扫一遍硬盘，把重复和"几乎一样"的照片分组列出来，你确认后一键移入废纸篓，可撤销。**

## 一、产品定义

三条不可动摇的原则：

1. **绝不联网** — 隐私是最大卖点
2. **绝不硬删除** — 只移废纸篓
3. **先预览后执行** — 没有确认绝不执行删除

这三条决定了产品敢不敢让陌生人把它指向自己的照片库。

## 二、技术方案

### 技术栈选择

| 方案 | 上手速度 | 体积/内存 | 评价 |
|---|---|---|---|
| Electron + React | 最快 | 大（~120MB） | 出活快，但"隐私小工具"配个大壳子别扭 |
| **Tauri 2 + React/TS + Rust** | 中 | 小（~8MB） | **选定**：体积小、内存低、隐私故事强 |
| Swift 原生 | 慢 | 最小 | 只做 macOS，另开 Windows 要重写 |
| Python + Qt | 中 | 中 | 打包分发坑多，不推荐做消费级 |

前端用 React/TS，重活（解码、哈希、并行）放 Rust。一套代码同时出 macOS 和 Windows。

### 核心算法

| 步骤 | 做法 | 关键点 |
|---|---|---|
| **精确重复** | 先按**文件大小**分桶，同大小的再算哈希 | 大小不同的绝不可能是同一文件，省掉 90% 计算 |
| **相似照片** | **dHash（64 位差分哈希）** | 缩到 9×8 灰度比相邻像素，抗缩放/转存/轻压缩 |
| **翻转容错** | 对水平翻转再算一次哈希一起比对 | 修图 App 常导出镜像版本 |
| **EXIF 方向** | 哈希前先按 EXIF 方向校正 | 否则竖拍照片会误判 |
| **快速分组** | 64 位切 4 段 ×16 位分桶（LSH） | 汉明距离 ≤3 必有一段相同（鸽巢原理） |
| **聚类** | **并查集（Union-Find）** | A≈B、B≈C 归成同一组 |
| **精确校验** | 候选对再算完整 64 位汉明距离 | 阈值可调 |

Rust 侧依赖：`image` 解码、`img_hash`/自研 dHash、`rayon` 并行、`trash` 移废纸篓、`rusqlite` 缓存。

### 性能与体验细节

- **增量缓存**：SQLite 存 `路径 + 修改时间 + 大小 + 哈希`，第二次扫描只处理新文件——"扫 5 万张不卡"的关键
- **HEIC 支持**：iPhone 用户大量是 HEIC，很多工具不支持——核心差异化点
- **保留最优策略**：默认保留「分辨率最高 → 文件最大 → 有 EXIF 相机信息 → 时间最早」，用户可改
- **安全**：删除前二次确认，删除后可撤销（记录操作批次）

## 三、UI 骨架（4 个界面）

1. **空状态**：一个大按钮「选择文件夹」+ 一句"你的照片不会离开这台电脑"
2. **扫描中**：进度条 + 实时计数（已扫 X 张 / 已发现 N 组重复）
3. **结果页**（核心）：左侧分组列表，右侧该组缩略图对比；每组默认勾选"要删的"；底部固定条：「共 N 组 · 可释放 X GB · [移入废纸篓]」
4. **设置**：相似度滑块、是否含子文件夹、忽略小于 X KB 的图、HEIC 开关

**v1 不做**：登录、云同步、相册管理、AI 分类。

## 四、打包与签名

| 平台 | 产物 | 签名要求 | 建议 |
|---|---|---|---|
| macOS | `.dmg` | Apple Developer $99/年 + 公证 | 初期发未签名版（右键打开），有量后立刻公证 |
| Windows | `.msi`/`.exe` | 代码签名证书（或 Azure Trusted Signing） | 未签名触发 SmartScreen 警告，转化掉一半 |

Tauri 自带 dmg/msi 打包，一条命令出包。

## 七、风险清单

- **误删恐惧**是这个品类的头号转化杀手 → 废纸篓 + 撤销 + 预览，缺一不可，文案反复强调
- **别做"AI 相似照片"**（CLIP 语义聚类）当卖点——准确率不稳、成本高、违背"离线"
- **竞品免费**：Windows PowerToys 等 → 差异化 = **HEIC + 中文 + 真离线 + 好用的对比 UI**
- **别一次扫整个磁盘**：默认让用户选文件夹，避免权限弹窗和超长扫描劝退
